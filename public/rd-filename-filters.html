Complete List of Real-Debrid's Filename Filters

I tested several thousand scene releases against Real-Debrid's torrent upload filter to map exactly which filename patterns trigger the infringing_file rejection (error_code 35). RD checks only the filename inside the .torrent metadata, it never downloads or inspects the actual file content.

Updated 3 October 2026. RD has changed the filter. I re-tested it with 121 fresh torrents and 12 file links, each torrent built over new data so only its name could decide. RD now refuses just five exact strings, and it now cares about upper and lower case. It also checks two different names: the torrent's own name when you add it, and each file's name when you open its download link. Everything below reflects the current behavior.

TL;DR: Five Exact Strings, Case-Sensitive

WEB-DL   WEB.x264   WEB.H264   HDTV.x264   HDTV.XviD

A name is refused if it contains one of these exactly as written, anywhere in the name. Upper and lower case must match: WEB.H264 is refused but WEB.h264, web.H264 and WEB.X264 pass. WEB-DL is refused but web-dl, Web-Dl, WEB.DL, WEBDL and WEB DL pass.

No longer blocked since October 2026: WEBRip, BDRip, HDRip, DVDRip, BluRay.x264, BluRay.DTS, lowercase WEB.h264, and every lower or mixed case spelling of the five.

Where RD looks

  • Adding a torrent: only the torrent's own name counts. A season pack named cleanly is accepted even when the episodes inside are called WEB-DL.
  • Opening a file's download link: each file's own name counts. Those WEB-DL episodes download fine but their links are refused with the same infringing_file error, while clean siblings in the same pack play normally.

Real-World Impact

  • All WEB-DL releases: AMZN/NF/DSNP/ATVP/HMAX/PMTP/iT/MA/TEN WEB-DLs
  • .WEB.H264 releases: HiggsBoson, SYLiX
  • .HDTV.x264 releases: SYNCOPY

Now safe: WEBRip, BDRip, DVDRip, BluRay.x264, .WEB.h264 scene releases (GRACE, ETHEL, EDITH), .WEB.h265, BluRay.x265, HEVC x265, TELESYNC, HDTS, DCP

Rule 1: WEB-DL

If the name contains WEB-DL, written exactly like that, it is refused. The file extension doesn't matter, and neither do brackets or spaces around it.
